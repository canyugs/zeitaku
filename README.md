# 改名契約所

一款在瀏覽器遊玩的漢字減筆改名契約遊戲。

## 遊玩

- [3D 版](https://canyugs.github.io/zeitaku/)
- [2D 版](https://canyugs.github.io/zeitaku/2d.html)

2D 與 3D 版共用同一套邏輯，只有呈現方式不同。
